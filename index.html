เครื่องมือนี้ใช้แบบจำลอง SGP4 คำนวณตำแหน่งดาวเทียมจาก TLE (ดึงโดย GitHub Actions จาก CelesTrak / SatNOGS DB ทุก 3 ชม.) เพื่อประมาณเวลาที่ดาวเทียมโคจรผ่านใกล้พิกัดเป้าหมายมากที่สุด (จุดใต้ดาวเทียม / Nadir Ground Track) ความแม่นยำขึ้นกับความสดใหม่ของ TLE และไม่ได้รวมมุมเอียงกล้อง (Off-nadir Pointing), การหมุนตัวดาวเทียม (Attitude), หรือความหน่วงของระบบภาคพื้นจริง — ใช้เป็นค่าประมาณเบื้องต้นก่อนตรวจสอบกับซอฟต์แวร์ควบคุมภารกิจจริงเสมอ
